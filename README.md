# O-Sistema-de-Comandas-para-Lanchonetes
instruções de instalação: npm install --legacy-peer-deps

O Sistema de Comandas para Lanchonetes foi desenvolvido com o objetivo de fornecer uma ferramenta simples, rápida e eficiente para o gerenciamento de pedidos em estabelecimentos alimentícios.
 O sistema permite criar comandas, visualizar histórico, adicionar novos itens, concluir ou editar pedidos e gerar relatórios visuais.
Todo o funcionamento ocorre no navegador, utilizando React + TypeScript, com armazenamento de dados feito em LocalStorage.
